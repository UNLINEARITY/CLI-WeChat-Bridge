# Version 1.0.4

**Release Date:** May 16, 2026

## Overview

Version 1.0.4 is a bridge reliability and release-confidence update. It makes OpenCode and Codex WeChat replies line up more closely with the visible local terminal result, prevents stale local session history from being sent back to WeChat on startup, and adds the quality and global-install checks needed to publish with more confidence.

This release also refreshes the README around the current npm workflow, one-command launchers, OpenCode support, and contributor validation path.

## Fixes

### OpenCode reply correctness

- OpenCode final replies now prefer the latest visible assistant message from the session instead of a 500-character output tail summary.
- Long visible OpenCode replies continue to be sent as one WeChat text message, preserving the same reading experience as the local terminal.
- Reasoning-only OpenCode parts and reasoning text deltas are ignored before WeChat forwarding.
- Local prompt echoes and WeChat-origin prompt echoes are excluded from the final reply buffer, so user input is not mixed into the assistant answer.
- If OpenCode emits only text that is removed by the visible-reply cleanup, WeChat receives a clear diagnostic message instead of a silent or misleading reply.

### Codex startup and session isolation

- Shared sessions are restored only when both the adapter and workspace match the persisted state.
- Starting Codex after an OpenCode session no longer restores an OpenCode-style `ses_...` shared session id.
- Codex startup seeds a session replay cutoff when there is no active WeChat turn, preventing historical local `mirrored_local_input` or `final_reply` events from being replayed to WeChat.

## Improvements

### Quality gate for source changes

- Added ESLint flat config for `bin`, `src`, and `test`.
- Added `npm run lint`, `npm run lint:fix`, `npm run typecheck:src`, and `npm run quality`.
- `npm run quality` now runs lint, source TypeScript checking, the full Bun test suite, and the build.
- Added a source-only TypeScript check so strict source errors are visible even though the publish build still uses the faster build config.
- Cleared the existing source TypeScript errors across bridge adapters, companion startup, WeChat transport, and update checking.
- Added a local `qrcode-terminal` declaration for the dependency's missing TypeScript types.

### Bridge adapter cleanup

- Extracted common bridge adapter helpers into `src/bridge/bridge-adapter-common.ts`.
- Kept the existing `bridge-adapters.shared.ts` re-export surface so current imports continue to work.
- Tightened metadata, nullable access, and event-shape handling for Codex, Claude, OpenCode, shell, and shared bridge helpers.

### Real global install smoke test

- Added `npm run smoke:global` for release and manual verification.
- The script now packs the current source tree into a real npm tarball and installs it with `npm install -g`.
- Safe global command shims are verified from the user's home directory through the real shell `PATH`, including Windows PowerShell shim resolution.
- `--purge-global` removes the currently installed global package before testing.
- `--clean-cache` clears the npm cache before packing and installing.
- `--full` runs the full quality gate before the smoke install.
- `--keep-tarball` keeps the generated tarball for inspection.
- If npm installs the shims but the current shell cannot resolve them, the script now reports a clear PATH error instead of passing a misleading temporary-prefix test.

### Documentation refresh

- The README now documents the current npm install path, global `wechat-setup`, one-command launchers, and manual two-terminal debugging mode.
- OpenCode is listed alongside Codex, Claude Code, and shell as a supported adapter.
- New README media assets make the project purpose and runtime flow easier to recognize.
- Removed stale standalone Codex guidance that no longer matched the current multi-adapter workflow.

## Upgrade Notes

After 1.0.4 is published, upgrade with:

```bash
npm install -g @unlinearity/cli-wechat-bridge@latest
```

Restart any running bridge and companion terminals after upgrading.

For release preparation or local verification from source, run:

```bash
npm run quality
npm run smoke:global -- --purge-global --clean-cache
```

`npm run smoke:global` intentionally changes the real global npm installation. Use it when you want the locally built package to remain available globally for follow-up manual checks.

## Compatibility

No breaking changes are expected. The package still requires Node.js `>=24.0.0` and Bun for the test workflow.
