# 版本 1.2.1

**发布日期：** 2026 年 9 月 28 日

## 概述

版本 1.2.1 在保留 OpenCode 1.18 支持的同时接入 OpenCode 2，让微信路由与可见 Codex 会话保持一致，并完成 Claude Code 切换模型时的二次确认。同时将 Codex CLI 已验证范围扩展至 0.157，并恢复已安装命令入口的可执行权限。

## 支持 OpenCode 2

bridge 现在同时支持 OpenCode 2 与 1.18。`wechat-opencode`、`wecom-opencode` 和 daemon 管理的 OpenCode 会根据已安装的 CLI 版本选用相应连接。可见终端会话、远程模型与计划模式控制、审批与提问、会话恢复、最终回复，以及在本地 TUI 中提交的提示词继续与远程通道连接。OpenCode 2 会转发已提交的本地提示词；其 TUI 不再发布草稿更新事件，因此输入中的草稿不会同步。每周 CLI 兼容性检查分别覆盖两条受支持的版本线。

## 可见会话与模型切换

- **Codex：** CLI 已验证范围现为 0.149–0.157。可见 Codex 终端打开 bridge 启动工作区内的会话时，微信会跟随该会话，不把无关的后台活动当作终端切换。如果终端打开其他工作区的会话，微信会收到提示，并暂停向旧会话发送输入，直到本工作区的会话重新启用。跨工作区暂停与恢复已有自动化测试覆盖，仍需进行实机验收。
- **Claude Code：** 通过 `/model <编号>` 选择模型时，现在会处理可见 CLI 额外显示的「Switch model?」确认框，包括默认模型的选择，并核对切换结果。其他确认框或目标不符的选项不会被自动确认。

## 启动命令可靠性

发布包中的 `wechat-*`、`wecom-*` 等命令入口保留可执行权限，全局安装后可以直接运行。bridge 仍仅调用 `PATH` 中独立安装的 CLI，不会调用桌面应用内部捆绑的可执行文件。

## 重要说明与升级

Node.js 最低版本保持 22.13.0；Pi 适配器需要 22.19.0 或更新版本。无需迁移数据，也无需更换命令。升级主包：

```bash
npm install -g cli-wechat-bridge@latest
```

已有的作用域包用户可以这样升级：

```bash
npm install -g @unlinearity/cli-wechat-bridge@latest
```

升级后请重启正在运行的 bridge、daemon 和可见 CLI 进程。Codex 路由仍绑定 bridge 的启动工作区；可见终端返回该工作区的会话后，消息转发会恢复。
